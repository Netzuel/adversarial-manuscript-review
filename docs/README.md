# Find your way through the review

Start with one manuscript and follow its changes through to the evidence. These guides separate everyday use from the details needed to extend or troubleshoot the skill.

## First run

1. Install for [Codex](README.codex.md) or [Claude Code](README.claude.md).
2. Follow the [synthetic quickstart](quickstart.md).
3. Read [workflow and outputs](workflow.md) to interpret the result.

## Use it on your own work

| If you need to… | Read |
|---|---|
| Check source and format requirements | [Formats and checks](formats.md) |
| Set expectations about rounds, stopping, and delivery | [Workflow and outputs](workflow.md) |
| Resume after an interruption | [Recovery](recovery.md) |
| Change interpreter, upgrade, disable, or uninstall | [Installation and removal](installation.md) |
| Resolve discovery, permission, or integrity problems | [Troubleshooting](troubleshooting.md) |
| Decide whether sensitive material is suitable | [Security and privacy](../SECURITY.md) |

## Understand or improve the skill

- [Architecture](architecture.md): responsibilities, shared runtime, and host adapters.
- [Verification](verification.md): deterministic checks and live-host evidence.
- [Fixtures](../fixtures/README.md): small synthetic cases and their intended checks.
- [Contributing](../CONTRIBUTING.md): development setup and submission guidance.
- [Changelog](../CHANGELOG.md): changes to behavior and documentation.

The [editor protocol](../skill/references/workflow.md) and [record interface](../skill/references/records.md) are the detailed instructions used during a run. You do not need to operate the helper manually for normal manuscript review.
