# Selective domain checks

Load only applicable checks and available installed scientific skills. These lists do not prove completeness.

- Numerical physics/PINNs: governing equations, IC/BC consistency, independent evaluation points, residual versus solution error, reference solver, convergence/resolution, seeds, benchmark parity.
- Quantum: dimensions, Hermiticity, normalization, conventions, unitary/open-system assumptions, observables, gradients, numerical checks and resource accounting.
- ML/statistics: preprocessing fit boundaries, train/test leakage, splits, baselines, variability, metric interpretation, ablation rationale, uncertainty assumptions.
- General theory: definitions, scope of quantifiers, assumptions, proof steps, counterexamples, edge and limiting cases.

Model judgment, executed numerical checks and formal proof are different evidence types. Only record a check as executed when a real command/output record exists. Do not remove assertions or widen tolerances to pass. Preserve raw numerical and figure provenance.
